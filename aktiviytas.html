📚 Tujuan Pembelajaran

Setelah mengerjakan LKPD, siswa diharapkan dapat memahami variable, fungsi variable, perbedaan let dan const, aturan penamaan variable, penyimpanan data teks dan angka, serta penggunaan console.log(). 

🧩 Aktivitas 1 — Mengamati

let nama = "Budi";
let umur = 16;
let nilai = 85;

console.log(nama);
console.log(umur);
console.log(nilai);
1. Apa yang ditampilkan pada Console?
Jawaban: Budi, 16, dan 85 ditampilkan pada Console.
2. Apa fungsi nama, umur, dan nilai?
Jawaban: Ketiganya adalah nama variable yang digunakan untuk menyimpan data nama, umur, dan nilai.
3. Apa yang terjadi jika console.log(nama) dijalankan?
Jawaban: Console menampilkan nilai yang tersimpan di variable nama, yaitu Budi.
4. Apa yang dimaksud dengan variable?
Jawaban: Variable adalah tempat untuk menyimpan sebuah data agar data tersebut dapat digunakan kembali oleh program.

🧪 Aktivitas 4 — Eksperimen

1. Apakah hasil pada Console berubah?
Ya. Hasil berubah sesuai data baru yang dimasukkan ke dalam variable.
2. Bagian kode mana yang diubah?
Bagian nilai pada variable nama, kelas, dan umur.
3. Mengapa program dapat menampilkan data yang baru?
Karena nilai yang disimpan dalam variable telah diubah sehingga console.log() menampilkan nilai terbaru.

🔄 Aktivitas 6 — let dan const

let umur = 16;
umur = 17;
console.log(umur);
Hasilnya adalah 17, karena nilai variable yang dibuat dengan let dapat diubah.

const nama = "Budi";
nama = "Andi";
Program menghasilkan error karena nilai variable const tidak dapat diubah setelah diberi nilai.
KeywordNilai dapat diubah?Kegunaan sederhana
letYaUntuk data yang masih mungkin berubah
constTidakUntuk data yang tidak perlu diubah

💭 Aktivitas 13 — Think Pair Share

Mengapa programmer membutuhkan variable?
Programmer membutuhkan variable untuk menyimpan data agar data tersebut dapat digunakan kembali oleh program. Dengan variable, program lebih mudah mengelola dan menggunakan data.

Kesimpulan kelompok:
Variable membantu program menyimpan berbagai data, seperti teks, angka, dan nilai boolean, sehingga data dapat digunakan dalam proses program.
