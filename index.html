Ringkasan Materi

Apa itu Variable?

Variable dapat dianggap sebagai tempat untuk menyimpan sebuah data agar data tersebut dapat digunakan kembali oleh program.

letnama="Andi"

Bagian dalam Variable

  • let → membuat variable
  • nama → nama variable
  • = → memberikan nilai
  • "Andi" → nilai yang disimpan
DAPAT BERUBAH

let

Digunakan untuk data yang masih mungkin berubah.

let nilai = 80;
nilai = 90;
TETAP

const

Digunakan untuk data yang tidak perlu diubah.

const namaSekolah =
"SMKN 1 Garut";
03

Aktivitas & Jawaban

Kode:

let nama = "Budi";
let umur = 16;
let nilai = 85;
console.log(nama);
console.log(umur);
console.log(nilai);

1. Apa yang ditampilkan pada Console?
Budi, 16, dan 85.

2. Fungsi nama, umur, dan nilai?
Ketiganya merupakan nama variable yang digunakan untuk menyimpan data.

3. Apa yang terjadi jika console.log(nama) dijalankan?
Console menampilkan nilai yang tersimpan pada variable nama, yaitu Budi.

4. Apa yang dimaksud variable?
Variable adalah tempat untuk menyimpan data agar dapat digunakan kembali oleh program.

Contoh program dengan data diri:

let nama = "Bintang Muhammad Rahman";
let kelas = "X PPLG 1";
let umur = 16;

console.log(nama);
console.log(kelas);
console.log(umur);

Jawaban eksperimen: Hasil pada Console berubah sesuai data baru karena nilai yang disimpan dalam variable telah diubah. Bagian yang diubah adalah nilai setelah tanda =.

VariableNilaiJenis Data
nama"Andi"String / teks

tinggi170Number / angka

✓ nama✓ namaSiswa✓ nama_siswa ✗ 2nama✗ nama siswa✓ nilaiAkhir ✓ nilai1✗ nilai-akhir✓ Alamat✓ alamatSiswa

Perbaikan: 2nama → nama2, nama siswa → namaSiswa, nilai-akhir → nilaiAkhir.
